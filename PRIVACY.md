# 🔒 Privacy Policy

Last updated: August 2026

**BerryMaster** is built with an **offline-first, privacy-by-design** philosophy. We believe that your gaming data, farming schedules, and personal notes should remain entirely on your own device.

---

## 1. What Data We Store (Local-Only)

All application data is stored **100% locally** on your device using local storage / SQLite:

* **Character Profiles**: In-game character names and regional plot assignments.
* **Farming Data**: Planted berry varieties, planting timestamps, watering statuses, and harvest timers.
* **Inventory & Economics**: Seed stock, berry counts, item prices, and profit calculations.
* **User Preferences**: Dark/Light mode theme selections, notification preferences, sound toggles.

**None of this data is ever transmitted to or stored on external cloud databases or third-party servers.**

---

## 2. PokeMMO Credentials & In-Game Data

* **Zero Credentials Requested**: BerryMaster **never** asks for, accesses, records, or stores your PokeMMO username, password, email address, or 2FA credentials.
* **Zero Process Inspection**: BerryMaster does not scan running system processes, read game memory, or access PokeMMO account files.

---

## 3. Network & Internet Connections

BerryMaster only connects to the internet for the following explicit, non-invasive purposes:

1. **GitHub Auto-Update Checks**:
   * The app checks the public GitHub API (`https://api.github.com/repos/abhijeet-mishra34/BerryMaster/releases/latest`) to determine if a newer version of BerryMaster is available for download.
   * No personally identifiable information (PII) is sent with this request.

2. **Optional User Feedback**:
   * If you choose to submit a bug report or feature suggestion through the in-app Feedback form, only the information you enter (feedback category, message, rating, and app version) is forwarded securely via Discord Webhook.
   * Submitting feedback is completely optional.

---

## 4. Third-Party Analytics & Advertising

* 🚫 **No Tracking Cookies**
* 🚫 **No Analytics SDKs** (e.g. Google Analytics, Mixpanel, Firebase Analytics)
* 🚫 **No Third-Party Advertising Networks**

---

## 5. Data Control & Deletion

Because all your data is stored locally on your machine or mobile device:
* You can wipe your data at any time by clicking **"Reset / Clear Data"** inside the app settings.
* Uninstalling the application or clearing application cache removes all stored data immediately.

---

BerryMaster is open-source. Anyone is free to audit the source code on GitHub to verify our data privacy and security claims:
